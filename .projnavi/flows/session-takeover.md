# Flow: session takeover and leases

An open session is reserved for one client at a time; a running task holds its session until it ends; the owner can take a session over from another client (decisions 2026-10-08 and 2026-10-09 in `docs/architecture.md`).

1. Core: `packages/core/src/sessions/SessionLeases.ts` keeps leases in a SQLite file beside the sessions DB (`<sessions_db>.leases`), shared by the service and local TUI processes. `acquire` (60-second lease, `SESSION_BUSY` when another owner holds it), `takeover` (moves the lease and any running hold), `hold` (reserves the session for running work and renews it), `release`, `assertAvailable`.
2. Runtime: `MarifoldRuntime.acquireSession`/`takeOverSession`/`releaseSession`/`assertSessionAvailable` (`packages/core/src/runtime/MarifoldRuntime.ts`); `createAgentRunner` passes `holdSession`/`checkSession`, and `AgentRunner.run` holds the lease for the whole run so the finished turn is still saved after the client leaves. Chat turns check availability in `packages/core/src/runtime/ChatTurns.ts`.
3. Service: `POST /v1/sessions/:id/lease` (body `{ takeover: true }` to take over) and `DELETE /v1/sessions/:id/lease` in `packages/service/src/SessionRoutes.ts`, keyed by the `x-marifold-session-owner` header.
4. Client: `packages/client/src/sessionLease.ts` — `acquireSessionLease`, `takeOverSessionLease`, `releaseSessionLease`, `isSessionBusy`, and `renewSessionLease` (15-second renewal; only `SESSION_BUSY` ends it and calls `onLost`). `packages/client/src/client.ts` generates the per-client owner id.
5. TUI: `packages/tui/src/ui/App.tsx` renews the lease and, on loss, stops following the run (cancels a local one); `packages/tui/src/core/RemoteRuntime.ts` maps lease calls to the client; `marifold --resume <id> --takeover` (`packages/cli/src/index.ts`, `packages/tui/src/runTui.tsx`, `packages/tui/src/ui/WorkspaceShell.tsx`).
6. Web: `apps/web/src/screens/agent/useSessionLease.ts` renews on an interval and on visibility, releases on pagehide, and exposes `takeOver`; `apps/web/src/screens/agent/useAgentController.ts` acquires on load and exposes `takeOverSession`, which `apps/web/src/screens/agent/AgentScreen.tsx` offers through `SessionBlockedBanner.tsx`.
7. Tests: `packages/core/tests/SessionLeases.test.ts`, `packages/client/tests/sessionLease.test.ts`, `packages/service/tests/MarifoldService.test.ts`, `apps/web/tests/screens/agentController.test.tsx`.
