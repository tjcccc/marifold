# marifold v0.60.0 — the first testflight release

Released 2026-08-25 · tag `v0.60.0` · [GitHub release](https://github.com/tjcccc/marifold/releases/tag/v0.60.0)

This is marifold’s first testflight release.

marifold is a small, serious local-first agent drifting in the AI wave. This is the first public build meant to leave its developer’s machine and be tried by someone else.

Install it with:

```sh
npm install -g marifold
marifold init
```

Run `marifold` for the terminal UI, or start the local service and open the browser UI:

```sh
marifold service start --daemon
```

Node.js 24 LTS is required. This is an early testing milestone: expect rough edges, and feedback is welcome.
